# Справка по языку Lyra

## Обзор

Lyra — предметно-ориентированный язык (DSL) для написания музыки.  
Файл `.lyra` содержит команды, описывающие ноты, время, дорожки и эффекты.  
Интерпретатор превращает описание в звук (WAV) или MIDI.

## Команды

### Глобальные настройки

| Команда | Описание | Пример |
|---------|----------|--------|
| `tempo <bpm>` | Темп (ударов в минуту) | `tempo 120` |
| `volume <0-100>` | Громкость | `volume 80` |
| `wave <тип>` | Волна по умолчанию | `wave square` |
| `instrument <тембр>` | Выбрать музыкальный инструмент | `instrument piano` |
| `drumkit <набор>` | Выбрать набор ударных | `drumkit rock` |
| `sound <режим>` | Эпоха или характер всего рендера | `sound fm` |
| `reverb <0-100>` | Комнатная реверберация | `reverb 25` |
| `delay <доли> <0-100>` | Эхо, синхронное с темпом | `delay 0.75 15` |
| `master <пресет>` | Формат готового мастера | `master streaming` |
| `peak <dB>` | Максимальный пик от -12 до 0 dB | `peak -1` |
| `fadein <доли>` | Плавное появление | `fadein 2` |
| `fadeout <доли>` | Плавное затухание | `fadeout 8` |
| `title <текст>` | Название в WAV | `title "Last Bloom"` |
| `artist <текст>` | Исполнитель в WAV | `artist "My Name"` |
| `album <текст>` | Альбом в WAV | `album "Boss Themes"` |

### Ноты и паузы

| Команда | Описание | Пример |
|---------|----------|--------|
| `note <нота> <длительность>` | Одна нота | `note C4 0.5` |
| `rest <длительность>` | Пауза | `rest 0.25` |
| `chord <ноты...> <длительность>` | Аккорд | `chord C4 E4 G4 1` |

**Формат ноты:** `C4`, `C#4`, `Db4`, `F#5` … (октава 0–8)

**Длительность** указывается в ударах (beats).

### Дорожки

```lyra
track melody {
  wave pulse
  note C4 1
  note E4 1
}

track bass {
  wave triangle
  note C3 2
}
```

Всё, что находится внутри `track { ... }`, играет параллельно с другими дорожками.

### Ударные

У каждой команды можно указать длительность шага: `kick 0.5`. Если она
пропущена, используется `0.25`.

| Команды | Звуки |
|---------|-------|
| `kick`, `snare`, `clap`, `rimshot` | Бочка, малый, хлопок, удар по ободу |
| `hihat`, `openhat`, `crash`, `ride` | Тарелки и закрытый/открытый хэт |
| `low_tom`, `tom`, `high_tom` | Низкий, средний и высокий том |
| `cowbell`, `shaker`, `tambourine` | Дополнительная перкуссия |
| `timpani`, `impact` | Литавры и кинематографический удар |

Любой звук также можно вызвать общей формой: `drum <имя> [длительность]`,
например `drum crash 1`.

Наборы `standard`, `rock`, `electronic`, `retro` и `orchestral` меняют
характер всех последующих ударных на дорожке:

```lyra
track drums {
  drumkit rock
  kick 0.5
  hihat 0.5
  snare 0.5
  openhat 0.5
}
```

### Циклы

```lyra
loop 4 {
  note C4 0.5
  note E4 0.5
}
```

## Волны

| Имя | Характер |
|-----|----------|
| `sine` | Чистый тон |
| `square` | Классический 8-bit |
| `triangle` | Мягкий chiptune |
| `saw` | Яркий / жужжащий |
| `pulse` | 25% duty (очень "игровой") |
| `noise` | Шум |

## Инструменты

Команда `instrument` включает отдельный процедурный тембр. Семплы и
SoundFont не нужны — звук синтезируется самой Lyra.

| Имя | Характер |
|-----|----------|
| `piano` | Акустическое пианино с естественным затуханием |
| `electric_piano` | Мягкое электропианино |
| `organ` | Долгий органный звук |
| `music_box`, `glockenspiel` | Музыкальная шкатулка и колокольчики |
| `strings`, `brass`, `flute` | Оркестровые краски |
| `guitar`, `electric_guitar` | Акустическая и перегруженная гитара |
| `synth_bass` | Плотный синтезаторный бас |

Старые волны тоже работают через `instrument square`, но для явного выбора
волны удобнее писать `wave square`.

## Режимы звучания и эффекты

| Режим | Характер |
|-------|----------|
| `4bit` | Игрушечные пищалки, около 6 кГц и 15 уровней громкости |
| `8bit` | Квадратные волны и грубый NES/Game Boy характер |
| `16bit` | Тёплый SNES/Mega Drive хорус и псевдо-инструменты |
| `32bit` | Тёмная ADPCM-подобная окраска ранних дисковых консолей |
| `64bit` | Более чистые тембры, медленная модуляция и атмосфера |
| `tracker` | Короткие хрустящие Amiga/MOD-подобные семплы |
| `fm` | Яркая металлическая фазовая модуляция Yamaha/Genesis |
| `chiptune_modern` | Чистый мастер с подмешанным 8-битным слоем |
| `modern` | Чистый высококачественный сигнал без ретро-окраски |

```lyra
tempo 136
sound 16bit
reverb 28
delay 0.75 13
```

Готовые оригинальные примеры всех эпох находятся в
`examples/sound_eras/`. Они используют знакомые жанры, но не копируют
мелодии существующих песен.

## Подготовка трека к публикации

Для обычной загрузки через музыкального дистрибьютора используйте:

```lyra
master streaming     # stereo, 48000 Hz, настоящий 24-bit PCM, пик -1 dB
title "Название трека"
artist "Имя исполнителя"
album "Название релиза"
fadein 1
fadeout 8
```

Другие пресеты:

| Пресет | Результат |
|--------|-----------|
| `master streaming` | Stereo, 48 кГц, 24-bit, пик -1 dB |
| `master cd` | Stereo, 44.1 кГц, 16-bit, пик -1 dB |
| `master hires` | Stereo, 96 кГц, 24-bit, пик -1 dB |

Точные параметры можно задать отдельно командами `samplerate 44100|48000|96000`,
`bitdepth 8|16|24`, `channels 1|2` и `peak <dB>`.

Панорама работает внутри дорожки: `pan -100` — полностью влево, `pan 0` —
по центру, `pan 100` — полностью вправо.

```lyra
track piano {
  instrument piano
  pan -25
  chord C4 E4 G4 4
}

track strings {
  instrument strings
  pan 25
  chord C4 E4 G4 4
}
```

Lyra создаёт технически подходящий мастер-WAV. Обложка, коды ISRC/UPC,
жанр, дата релиза и окончательная проверка требований добавляются уже в
кабинете выбранного дистрибьютора.

## Запуск как у Python

```bash
lyra main.lyra                 # сразу исполнить файл
lyra run main.lyra song.wav    # то же самое, но явно
lyra check main.lyra           # проверить синтаксис без создания звука
lyra init main.lyra            # создать стартовый файл
lyra --version
```

Чтобы команда `lyra` работала из любой папки, собранный исполняемый файл
должен находиться в системном `PATH`.

## Экспорт

```bash
./lyra song.lyra                 # → song.wav
./lyra -f midi song.lyra         # → song.mid
./lyra -f aiff song.lyra         # → song.aiff
./lyra -f json song.lyra         # → song.json (события композиции)
./lyra -f flac song.lyra         # → song.flac (нужен FFmpeg)
./lyra -f mp3 song.lyra          # → song.mp3 (нужен FFmpeg)
./lyra -f ogg song.lyra          # → song.ogg (нужен FFmpeg)
```

WAV, MIDI, AIFF и JSON экспортируются самим Lyra. Для сжатых форматов команда
`ffmpeg` должна быть доступна через системный `PATH`.

## Обработка ошибок

Парсер всегда указывает номер строки и понятное сообщение.
