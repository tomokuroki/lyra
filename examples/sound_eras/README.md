# Lyra sound-era examples

These are original sketches in familiar popular genres. They demonstrate
sound palettes and production ideas without copying melodies from existing
songs or games.

1. `01_4bit_toy_march.lyra` — toy march
2. `02_8bit_arcade_runner.lyra` — arcade action
3. `03_16bit_jrpg_battle.lyra` — JRPG battle
4. `04_32bit_dance_stage.lyra` — early-console dance stage
5. `05_64bit_forest_temple.lyra` — atmospheric adventure
6. `06_tracker_breakbeat.lyra` — Amiga-style breakbeat
7. `07_fm_neon_highway.lyra` — FM synthwave
8. `08_modern_chiptune_drop.lyra` — modern chiptune/EDM
